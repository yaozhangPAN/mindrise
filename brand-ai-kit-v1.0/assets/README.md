# Logo Assets

| 文件 | 用途 |
|---|---|
| `logo-horizontal-wanwu-teal.png` | 浅色背景的横版主标志，透明底 |
| `logo-vertical-wanwu-teal.png` | 浅色背景的竖版主标志，透明底 |
| `logo-vertical-white.png` | 万物青等深色背景上的反白主标志，透明底 |
| `symbol-wanwu-teal.png` | 小尺寸万物青三叶符号，透明底 |
| `symbol-sprout-green.png` | 动态或数字场景中的灵芽绿符号，透明底 |
| `wanwu-youling-logo-vector-master.pdf` | 原始矢量主文件，包含横版、竖版与背景版本 |

使用Logo前请同时遵守 `BRAND.md` 中的安全空间、最小尺寸与禁用规则。
